# CLI Library for ArduinOS

This library provides functions to enable asynchronous Command Line Interface (CLI) operations for the ArduinOS project. It is designed to handle non-blocking input and output, making it suitable for real-time systems.

## Features
- Asynchronous command parsing
- Non-blocking input handling
- Support for custom command registration
- Lightweight and efficient
